Research paper style output. With inline refereces. For example "bla bla bla [1]".

First start with the Exceptable Resources. If a questions cannot be answered or information is
not found. Prompt user to widen search before moving away from the exceptable resources.

## Output style (ADHD: short and to the point)

Apply the /i-have-adhd shape to every srch response:
1. Lead with the answer (the direct finding), not setup or a plan.
2. Keep findings tight: one idea per sentence, rank most relevant first, cap visible points at 5.
3. No preamble, no recap, no closers.
4. State time estimates in concrete units when relevant.
5. Keep it simple, stupid

This shapes presentation only; it must not limit how many sources you search or facts you gather.
Provide an example when able

## Exceptable Resrouces
Links to resources go here. recommendations are docs pages and repos. Anything you want the agent
to use to answer then reference.
